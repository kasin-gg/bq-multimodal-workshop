# Build Multimodal Apps with BigQuery and Vertex AI — Hands-On Workshop

Hands-on lab modules and setup scripts for indexing, describing, and searching unstructured images, audio, and documents inside **Google BigQuery** using **Object Tables**, **Vertex AI Gemini**, multimodal embeddings, and vector search.

Used in live developer code-along workshops with Google Developer Groups Cloud Bangkok (`asia-southeast3` Bangkok region configuration).
